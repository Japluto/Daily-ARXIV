    家庭移动操作论文精选｜2026-10-09

    本期精选20篇，按与你RP的相关性、实验可信度和研究价值排序。筛选窗口为2026-10-02至2026-10-09本次检索时点；条目日期采用arXiv的UTC投稿记录。20篇均为窗口内首发；ROMA另有10月8日v2记录，本期实验核查以可读的v1为准。

    其中5篇直接涉及移动操作或导航后底座位姿变化；其余是与动作表示、证据记忆、主动感知和WAM评估直接相关的工作，明确标注平台边界。实验数字来自论文全文/附录，RMMBench核查了PDF和官方项目；这些是作者报告结果，不能跨论文排行榜直接比较。

    RP比较采用你10月8日明确的流程图：证据记忆与因果阶段belief→校准后的技能readiness→act/observe/reposition→固定技能执行及结果验证。未获取完整最新版RP正文，因此下面的novelty判断均为基于该流程与本期证据的推断，不等于完成全领域查新。

    建议用三个互相独立的分类轴，而不是把“大系统、trick、VLA、WM、agentic coding”放在同一组：

    分类轴标签判断原则
    贡献类型大系统／核心方法／模块或trick／数据／基准与诊断看主要贡献和因果消融；大系统与小模块可以并存，trick不代表低价值。
    技术路线VLA／WM-WAM／Agent与代码编排；允许多标签区分学动作、预测世界、选择或生成执行程序；agentic coding通常是编排层。
    动作层级底座＋臂连续控制／metric或grid接口／技能与阶段／观测与规划重点问表示是否真的改变，以及是否有底座与臂联合闭环验证。

    筛选先按RP相关性、原始实验质量、可复现信息及新意排序，再按标签组织；不按VLA/WM/Agent平均分配名额，也不因系统规模或宣传热度加分。你可先精读前5篇，再用第6—8、14篇建立移动操作实验边界。

    先核实两篇旧基准的真实贡献：

    Acting in Meters: Learning Metric Interactions for Precise Robotic Manipulation：9月旧文，不占本期名额。核心是物体相对的末端交互轨迹ICT与动作联合去噪，以及基于点云几何的MAIF动作流修正；保留原生动作表示，不能概括成“把全部动作改成metric/grid”。因此“加入米制几何”与“提出统一动作空间”是两种不同主张。

    GAS-Robo：仅取得IEEE原始索引摘要，确认Grid Action Space连接LLM与Franka操作。全文未能获取，所以不能核实完整编码、消融和适用边界，也不能据此宣布你的方案被完全覆盖。它至少要求RP区别“grid作为接口”与“grid带来新的决策或泛化机制”。

    1. MobiAgent: Dual-Loop Recursive Policy Self-Improvement for Long-Horizon Mobile Manipulation
    日期：2026-10-02｜大系统｜Agent＋VLA｜移动操作、技能层

    • 核心贡献：用高层原子技能、专用动作头、视觉critic及全局重规划组成执行闭环，并用部署轨迹迭代改进策略。
    • 实验与局限：BEHAVIOR四任务各10次，Galaxea R1 Pro模型：成功率65%，π0.5-TA为42.5%；去critic降至10%。真实Astribot S1四任务，两轮更新从32.5%升至57.5%。 任务集较小，且闭环控制与策略更新同时存在，不能把全部收益归因于动作抽象。
    • 与RP关系及阅读理由：技能选择、结果验证、重规划已明显重合；可保留的候选问题是固定技能下前瞻readiness校准与主动观测成本。阅读价值：最直接的家庭移动系统基线。

    2. ProactiveVLA: Augmenting Embodied Memory through Proactive Environment Exploration
    日期：2026-10-04｜核心方法＋系统｜Agent/代码编排＋冻结VLA｜探索与记忆

    • 核心贡献：任务完成后利用剩余预算主动探索，并把成功、失败、不确定结果和恢复信息写入可复用记忆。
    • 实验与局限：以同一Codex/HarnessVLA为基线，评估LIBERO-Pro的8种设置和RoboCasa365的16个组合任务；Goal-T且最多调用一次VLA时为48%对19%。 48%属于受限调用子设置，不能当作整体成功率；评估以模拟任务为主，尚非真实底座＋臂验证。
    • 与RP关系及阅读理由：固定技能、证据记忆、探索及验证直接重合；重点区分跨任务预探索与当前状态下的readiness判断。阅读价值：最接近你的上层闭环，必须逐项对照。

    3. EvoMem-VLA: State-Evolution Memory for Long-Horizon Robot Manipulation
    日期：2026-10-04｜核心方法｜VLA｜状态变化记忆

    • 核心贡献：把有来源帧的状态变化tokens与多尺度历史结合，通过子任务/动作两种路由生成后续动作。
    • 实验与局限：RMBench九任务、每任务100回合，80.7%对EventVLA（VA only）的67.8%；去delta tokens为52.3%。真实Franka/AgileX COBOT四任务、合计80次，83.8%对πMEM的30%。 真实证据来自固定机械臂，没有检验移动后的坐标变化、可达性或观测缺失。
    • 与RP关系及阅读理由：“保存变化和结果证据”本身重合；在线因果阶段belief、证据失效与概率校准仍需独立验证。阅读价值：建立memory-only强基线。

    4. Unitas: A 3D-Native World Action Model for Embodied Manipulation
    日期：2026-10-08｜核心方法｜WAM｜统一metric 3D表示

    • 核心贡献：在共同米制3D框架中表示机器人/人手轨迹的action flow及场景点位移的scene flow，并统一物理时间尺度。
    • 实验与局限：1.7B模型LIBERO成功率99.8%、真实任务平均85%；RoboTwin场景预测相对PointWorld的Static ADE降低49%。 混合人类与机器人数据并不等于已证明底座＋臂联合闭环；与RP平台的迁移仍待验证。
    • 与RP关系及阅读理由：对“统一metric action representation”这一宽泛novelty构成直接挑战；可转向表示如何支持技能可执行性和观测决策。阅读价值：本期最重要的表示边界论文。

    5. Does a Learned Corrector Beat a Simple Retreat? Evidence from a Frozen VLA
    日期：2026-10-02｜诊断研究｜冻结VLA＋纠错｜执行干预

    • 核心贡献：用同初始条件的配对实验区分学习纠错、简单后退与随机重跑的真实作用。
    • 实验与局限：RoboTwin四任务3,888组配对；一个任务提升13.5个百分点，95% CI为9.4—17.7，其余三任务合并仅0.7点，CI跨零。计时触发的脚本后退提升15.3点，与学习方法未检出差异。 “未检出差异”不等于证明等效；训练依赖特权teacher，不能把teacher当可部署组件。
    • 与RP关系及阅读理由：对readiness触发机制提出关键证据要求：必须胜过定时observe/retreat、重跑及几何规则。阅读价值：防止RP收益实际来自多一次尝试。

    6. SimVLA: Zero-Shot Sim-to-Real VLA Learning for Mobile Manipulation
    日期：2026-10-08｜大系统＋数据｜VLA｜底座＋双臂连续动作

    • 核心贡献：以35类模拟移动任务、几何VQA及策略rollout训练，无真实示范微调地迁移移动操作。
    • 实验与局限：真实Anubis在模拟厨房布置、pantry及家庭五任务共2,120次rollout，平均任务进度54.4%，超过每任务50条真实示范微调的π0.5。200条示范π0.5从域内67.8%进度降到pantry的21.3%。 54.4%是子目标完成进度，非整任务成功率；训练利用模拟特权几何。
    • 与RP关系及阅读理由：补充低层动作与空间泛化基线，提醒readiness收益需与训练覆盖率区分。阅读价值：本期最强的直接移动sim-to-real证据之一。

    7. MobileVISTA: Generative Data Augmentation for Pose Generalization in Mobile Manipulation
    日期：2026-10-05｜数据方法｜几何增强＋策略学习｜导航后位姿

    • 核心贡献：同步重投影RGB-D、重渲染机器人及重定向动作，以增强操纵策略对底座停车偏差的鲁棒性。
    • 实验与局限：四模拟任务对Canonical、DP3、π0.5及GEN3C；15 cm扰动Can Sort为53%对Canonical的12%。真实R1 Pro洗衣分类，至少处理一件为18/25，对微调π0.5的14/25。 主要检验park-and-manipulate；依赖RGB-D、机器人模型及IK。典型位姿的Book Stacking为18/25，低于Canonical与微调π0.5的24—25/25，存在精度代价。
    • 与RP关系及阅读理由：不是统一底座＋臂动作表示创新；与reposition互补，需比较“改变站位”与“策略本身增强”。阅读价值：设计停车误差与站位测试。

    8. VOMMI: Collecting and Leveraging Portable Demonstrations for Mobile Manipulation
    日期：2026-10-06｜数据＋模块｜VLA｜底座/臂分组与局部运动tokens

    • 核心贡献：用便携RGB示范离线恢复身体/手运动，在线局部运动tokens与分组适配器改善底座动作。
    • 实验与局限：轮足DeepRobotics M20S＋CM1臂，三任务各20次，平均成功率58.3%对OpenPI 0.5的50%；柜门任务反而50%对65%。相对机器人示范训练参考，底座动作MAE降低18.2%。 离线重建使用整段轨迹与锚点，不能当成在线信息；仍有漂移，且只验证一种机体。
    • 与RP关系及阅读理由：互补于坐标系、ego-motion和动作分组；readiness应避免把定位漂移误判为阶段变化。阅读价值：直接检查底座动作信息从哪里来。
